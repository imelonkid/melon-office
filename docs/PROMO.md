# 宣传页与媒体素材

主题：**我的 AI 员工，入职大厂了。** 工区、工卡与猫共同构成主视觉。黑色外场、米黄墙面、薄荷绿和暖黄沿用项目的视觉语言。

## 静态 Hero

页面位于产品仓库 `site/`，按 melon-ops / project-init 基线 v3 的「静态宣传页」维护：纯 HTML、CSS、图片与少量脚本，无构建依赖。运行 `npm run promo:preview`，访问 `http://127.0.0.1:5175/`；也可直接打开 `site/index.html`。应用的 Vite 构建不包含宣传页。宣传页没有动画循环，不引入 Phaser、不连接 WebSocket、hooks 或外部模型，也不读取本地任务；脚本仅处理中文/英文切换。下载与 GitHub 按钮指向项目现有公开入口。

桌面布局为主题文案、等距工区及前景工卡。手机布局将工卡下移，保留工区与行政猫。工卡复用实际档案中的夹扣、角色头像、岗位、来源、工作状态和任务摘要样式。页面中的姓名、项目、在岗时长属于固定示例档案。

静态工区图片：`site/assets/office-hero-v1.png`；工卡头像：`site/assets/tian-portrait-v1.png`。所有依赖均在 `site/` 内，不依赖宣传视频、本地桥接或 Node 服务。资源采用版本化文件名；上线后修改图片、样式或脚本须换文件名，避免长缓存影响。

## 离线生成

依赖 macOS AppKit、Swift 编译器和 FFmpeg；不需要 API Key。运行：

```bash
npm run promo:render
```

`tools/render_promo.swift` 只读取仓库里的场景、角色图集及布局导航，生成固定剧情；人物经过现有通道，老板穿过玻璃门。`scripts/render-promo.sh` 编译渲染器、编码视频，并生成网页静态图。

输出在被 Git 忽略的 `promo-output/`，避免把视频产物放入源代码历史：

| 文件 | 内容 |
| --- | --- |
| `hero-1920x1080.png` | 中文 Hero 静态设计稿，包含工区与工卡 |
| `x-cover-1920x1080.png` | 英文横版封面，包含工区与工卡 |
| `xiaohongshu-cover-1080x1920.png` | 中文竖版封面，包含工卡与猫 |
| `x-promo-1920x1080.mp4` | 20 秒、20 fps、H.264 / yuv420p，英文横版，无声 |
| `xiaohongshu-promo-1080x1920.mp4` | 20 秒、20 fps、H.264 / yuv420p，中文竖版，无声 |
| `x-promo-960x540.gif` | 20 秒、10 fps，横版循环 GIF |

视频四幕各五秒：开工 → 举手找老板 → 交付喝咖啡/撸猫 → 老板出现、大家假装忙碌。影片与封面使用「演示」标记，03:00 和工卡数据是创作示例，均不来自真实会话。横版含公开 GitHub 地址；竖版使用项目与甜瓜科技署名。没有自动发帖、合并或发布步骤。

Hero PNG 是独立宣传设计稿，并非网页截图；HTML 的布局应在桌面和手机浏览器中分别验收。

## 验证

代码按 `scripts/ci-test.sh` 执行基线检查。渲染后使用 `ffprobe` 核对尺寸、时长、帧数与编码，并抽取各剧情节点检查文字、工卡、通道和透明素材。视频默认不含配音和音乐，可在剪辑时补充。

## 后续部署

按项目基线「静态宣传页」使用 `scripts/deploy-page.sh`，脚本来自 project-init 模板，仅将服务名设为拟登记的 `melon-office-page`，页面目录为 `site`。它与桌面端发布完全独立：

- 页面使用 `page-v*`；桌面端继续使用原有版本前缀和门户。
- 页面只允许从已推送的干净 main 发布，通过环境变量 `PAGE_DEPLOY_SSH` 调用部署入口；不在公开仓库写主机地址、站点目录或部署密钥。
- 部署入口从 GitHub 对应 tag 取 `site/`，原子切换版本并支持回滚；不使用 rsync、不起容器、不增加 Dockerfile 或 `/health`。
- 用户确认上线前，由 melon-ops 完成腾讯站服务注册、部署入口与限定钥匙、反代、DNS/证书及 Gatus 首页探活；这些目前尚未登记或部署。本次只完成页面和仓库内发布准备，不运行发布命令、不创建标签。
